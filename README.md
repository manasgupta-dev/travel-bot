# Travel Bot Phase 1

A minimal Slack bot using Python, slack-bolt, and Socket Mode.

## Setup

1. Install dependencies:
   ```bash
   pip install -r requirements.txt
   ```
2. Add your Slack tokens to `.env`:
   ```text
   SLACK_BOT_TOKEN=
   SLACK_APP_TOKEN=
   ```

## Run

```bash
python app.py
```

Use the `/travel` command in Slack to test.
